# dsh-gateway

连接 dsh（DeepSeek Harness）与聊天应用的 channel 网关，把聊天应用的私聊和群聊作为 dsh agent 的消息通道。

## 开发与验证

仓库处于项目初始化阶段，技术栈、dsh 接入方式与首个聊天平台接入方案尚未确定。目前没有可执行的安装、启动、构建或测试命令，也没有已定义的配置项与环境变量清单。
